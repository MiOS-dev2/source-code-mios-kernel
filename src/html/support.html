1. Getting Started

MiUX is a small hobby operating system written in Rust. This support center explains the main features and how to use them.

  • Boot MiUX from GRUB or your bootloader
  • Log in using one of the default accounts
  • Use the Start menu to launch applications
  • Open the terminal for advanced control

2. Default Users

MiUX ships with three pre-configured accounts:

UserPasswordRole
adminadminAdministrator
systemsystemSystem
useruserRegular user

3. Terminal Commands

Open the Terminal from the Start menu or the desktop icon. Then type help to see all commands.

  • help - list all commands
  • ver - show MiUX version
  • about - about MiUX
  • fs - filesystem information
  • dir - list directory
  • whoami - current user
  • users - list users
  • html /start - open the HTML viewer
  • support - open this support center
  • media - open the BMP image viewer
  • gl /start - open 3D gears demo
  • task /start - open Task Manager
  • calendar /start - open Calendar
  • cre-tool - open Cre Tool (app builder)
  • ext4 - mount EXT4 filesystem

4. User Management

To add a new user (admin rights required):

  • useradd <name> <password> - create a regular user
  • useradd <name> <password> admin - create an admin
  • userdel <name> - delete a user
  • passwd <name> <new_password> - change password

5. Filesystem

MiUX supports FAT32 and EXT4 filesystems.

  • mount <disk_number> - mount a FAT32 disk
  • ext4 - try to mount EXT4 on disk 0
  • ext4ls - list EXT4 root directory
  • ext4cat <file> - read an EXT4 file
  • ext4info - show EXT4 filesystem info

6. Applications

All built-in apps can be launched from the Start menu:

  • Terminal - command-line shell
  • File Manager - browse disks and files
  • Notepad - simple text editor
  • Paint - drawing application
  • Settings - wallpaper and theme options
  • AboutOS - system information
  • Media - BMP image viewer
  • HTML Viewer - HTML4 browser
  • Support Center - this page
  • Task Manager - running processes
  • Calendar - date and time
  • GL Demo - rotating 3D gears
  • Cre Tool - GUI app builder

7. Keyboard Shortcuts

  • Arrow Up / Down - scroll this page (in HTML/Support windows)
  • Click buttons with the mouse
  • Right click on the desktop for context menu
  • Click the clock in the taskbar to open the clock window

8. Customization

Open Settings from the Start menu to:

  • Change the desktop wallpaper (color or BMP)
  • Switch between Aero, Aero Dark and Aero Cool themes
  • Enable Live Wallpaper (auto-changing BMP wallpaper)

9. Troubleshooting

If something does not work:

  • Make sure you are logged in as admin for administrative tasks
  • Try cls in the terminal to clear the screen
  • Reboot from the Start menu if the system becomes unresponsive
  • Check the terminal output for error codes
