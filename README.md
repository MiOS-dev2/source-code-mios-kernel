**Исходный код ядра MiOS!**
Это исходный код голово ядра системы!
Здесь имеется графический интерфейс каторый можно запустить с помощью комманды gui /start 
Так же из графического режима можно выйти написав комманду gui /stopИсходный код ядра MiOS
1 - системные зависимости и настройка
Перед тем как начать компиляцию Mi-Kernel необхлжимо выполнить эти комманды:
Обновление пакетов
sudo apt update && sudo apt upgrade -y
Основные инструменты сборки
sudo apt install -y build-essential
NASM (ассемблер для загрузчика)
sudo apt install -y nasm
GRUB и инструменты для создания ISO
sudo apt install -y grub-pc-bin grub-common xorriso mtools
QEMU для эмуляции
sudo apt install -y qemu-system-x86 qemu-kvm
Зависимости для Rust (если ещё не установлен)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
После установки Rust перезагрузите терминал и выполните:
source ~/.cargo/env
Затем настройка Rust для проекта
make setup
2 - где и что менять?
Если ты знаешь хоть что-то про Rust то ты не должен сюда идти, но если ты не знаешь, то вот список:
Код основоного ядра
Код основого ядра системы находится в папке src в файле lib.rs
в код ядра входит:
Инициализация процессов загрузки
работа с коммандной строкой
минимальная работа с графическим интерфейсом
работа и инициализация мыши
Код Secure версии ядра
Код безопасной версии ядра находится в папке src_secure в файле lib.rs
В код безопасного ядра входит:
Инициализация процессов загрузки
работа с коммандной строкой
минимальная работа с графическим интерфейсом
работа и инициализация мыши
безопасный контейнер
Код GUI версии ядра
Код графической версии ядра находится в папке src_gui в файле lib.rs
В код графической версии ядра входит:
Инициализация процессов загрузки
работа с коммандной строкой
полная работа с графическим интерфейсом
работа и инициализация мыши
3 - GRUB
Загрузчиком ядра выступает GNU/GRUB 2.12 с vbe mode
сами параметры GRUB ЕСТЬ ТОЛЬКО В makefile!!!
grub.cfg создаётся после компиляции
4 - поддержка FAT32
В ядре есть наработки fat32, НО они не полные!!!
если вы хотите допилить fat32 то весь код fat32 есть в папке fs!
